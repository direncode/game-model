UNITED STATES PATENT
US 10,097,351 B1
GENERATING A LATTICE BASIS FOR LATTICE-BASED CRYPTOGRAPHY
Inventors: Shane Daniel Kelly, Filip Kostis Pawlega, Kassem Kalach
Assignee: Isara Corp
Issued: October 9, 2018

ABSTRACT
The patent describes generating a lattice basis parameter for post-quantum cryptography by combining a fixed global system parameter with independently generated pseudorandom elements. This hybrid approach reduces computational overhead while mitigating "all for the price of one" geometric attacks against fixed lattice schemes.

BACKGROUND

Lattice-based cryptography is a leading candidate for post-quantum cryptographic systems. The security of lattice-based schemes relies on the computational hardness of certain lattice problems, primarily the Learning With Errors (LWE) problem and its variants (Ring-LWE, Module-LWE).

A core challenge in lattice cryptography is balancing security against fixed lattice vulnerabilities with computational efficiency. Two extreme approaches exist:

1. Fixed lattices: A single global lattice basis is shared by all users. This enables efficient implementations but creates "all for the price of one" attacks where a single computationally expensive precomputation can compromise all users.

2. Random lattices: Each user generates a fresh random lattice basis. This eliminates the precomputation attack but requires expensive seed expansion for each transaction (approximately 40% of "Frodo" key-exchange computation is spent generating the lattice basis).

The present invention provides a middle path: a lattice basis that combines fixed and random elements via a mask pattern.

LATTICE-BASED CRYPTOGRAPHY FUNDAMENTALS

Modern lattice-based cryptosystems rely on the difficulty of the Learning With Errors (LWE) problem. Given a matrix A and a vector b = A*s + e where s is a secret vector and e is a small error, recovering s is computationally hard.

The system uses operations on lattices with the following components:
- Lattice basis matrix A (or vector for Ring-LWE)
- Secret key s (small coefficients)
- Error term e (small Gaussian-distributed)
- Public key b = A*s + e

Encryption proceeds by computing inner products with the public key plus error.
Decryption uses the secret key and the structure of the lattice to recover the original message.

KEY INNOVATION

Rather than fixing the entire lattice or randomizing it completely, the invention uses a mask pattern to designate which matrix positions come from a public parameter B and which are freshly generated from a seed.

Example: if half the entries of the matrix B are masked as "holes" (regenerated from seed), this implies a 50% improvement in performance compared to fully regenerating the lattice basis.

The masked positions are filled with pseudorandom elements derived from a fresh seed, while the unmasked positions use the fixed global parameter. This provides both:
- Performance: only a fraction of the matrix needs fresh generation
- Security: enough randomness to resist precomputation attacks against the fixed component

POST-QUANTUM RESISTANCE

The system is designed for post-quantum security. The underlying hard problem (LWE in lattices) is believed to resist quantum attack because:
1. No known quantum algorithm provides exponential speedup for SVP or LWE
2. Worst-case to average-case reductions exist for certain lattice problems
3. The error distribution provides additional security against algebraic attacks

The patent specifically targets quantum-resistant key agreement, signatures, and encryption protocols.

IMPLEMENTATIONS

Matrix-based (LWE/Frodo-style):
- Full matrix A as the lattice basis
- Apply mask pattern to designate fixed vs random positions
- Suitable for applications where computational cost can be amortized

Vector-based (Ring-LWE/New Hope-style):
- Polynomial vector representation
- Apply mask pattern to polynomial coefficients
- More efficient but with structural assumptions

CLAIMS

1. A method for generating a lattice basis parameter comprising combining a fixed global system parameter with pseudorandomly generated elements according to a mask pattern.

2. The method of claim 1 wherein the mask pattern designates a subset of positions in the lattice basis matrix that are filled from the fixed global parameter, with remaining positions filled by pseudorandom elements derived from a seed.

3. A cryptographic system comprising the lattice basis generated by the method of claim 1, configured for post-quantum key exchange, encryption, or digital signature.

4. The system of claim 3 wherein the cryptographic operations are based on the Learning With Errors (LWE) problem.

5. The system of claim 3 wherein the cryptographic operations are based on the Ring-LWE or Module-LWE variants.

6. The method of claim 1 wherein the mask pattern is selected to provide at least 25% performance improvement over fully random lattice generation.

7. A post-quantum key exchange protocol using the lattice basis of claim 1.

This patent represents a modern (2018) implementation of post-quantum lattice-based cryptography. It builds on the lattice-based cryptography lineage starting with NTRU (1998-2001) and continuing through Regev's LWE formulation (2005), Ring-LWE schemes, and current NIST PQC candidates including Kyber, Dilithium, and Falcon.

The mathematical foundation is the same as NTRU: hardness of lattice problems, particularly the shortest vector problem and the learning with errors problem. The system uses lattice operations and is designed to resist quantum computer attack.
